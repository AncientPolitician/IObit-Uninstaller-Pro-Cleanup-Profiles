## Usage

### For Software Uninstallation:
1. Launch IObit Uninstaller Pro and navigate to the **All Programs** section.
2. Load an uninstall profile via **File** → **Load Profile**.
3. Select the profile matching your uninstall scenario (e.g., "Gaming Software Cleanup", "Antivirus Removal").
4. Review the list of detected applications and select those to remove.
5. Use the **Powerful Scan** feature for thorough residual file removal.
6. Complete the uninstallation and verify the system state.

### For Registry Cleaning:
1. Open the **Registry Cleaner** module.
2. Load a registry cleanup preset from the collection.
3. Choose the scan depth (Quick, Deep, or Custom).
4. Run the scan and review the found issues.
5. Select the items to fix or remove.
6. Create a restore point before making changes.

### For System Junk Cleanup:
1. Select the **System Cleanup** tool.
2. Load a junk file cleaner profile.
3. Configure the categories to scan (temporary files, cache, logs, etc.).
4. Run the scan and review the files to be deleted.
5. Remove the junk files and monitor freed space.
6. Schedule regular cleanups using the provided scripts.

### For Browser Extension Management:
1. Apply the browser extension remover profile.
2. Select the browser you want to clean (Chrome, Firefox, Edge, etc.).
3. Review the list of extensions and toolbars.
4. Remove unwanted or suspicious extensions.
5. Restart the browser and verify the changes.

### For Batch Uninstall:
1. Load a batch uninstall configuration.
2. Select the multiple applications you want to remove.
3. Choose the uninstall method (Standard, Powerful, or Force).
4. Review the list and confirm the removal.
5. Monitor the batch uninstall progress.
6. Clean up remaining files using the Powerful Scan.

### For Scheduled Maintenance:
1. Open the **Settings** → **Scheduler** section.
2. Load a scheduled cleanup template.
3. Set the frequency and time for automated maintenance.
4. Configure the cleanup tasks (registry, junk files, software).
5. Enable notifications for task completion.
6. Save the schedule and monitor its execution.

### Automation Tips:
1. Use the batch scripts for silent uninstallation across multiple systems.
2. Schedule weekly system cleanups to maintain performance.
3. Configure automatic restore points before major uninstallations.
4. Create custom profiles for specialized software environments.
5. Use the command-line interface for remote management.
